# DEAD SECTOR · القطاع الميت

لعبة تصويب زومبي ثلاثية الأبعاد بمنظور الشخص الأول — تعمل على الهاتف واللابتوب.
مبنية من الصفر بـ **three.js + Vite**، وكل النماذج والصوتيات والإضاءة مولّدة برمجياً (صفر أصول خارجية).

## التشغيل

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
npm run preview  # http://localhost:4173
```

## البنية

| المسار | الوصف |
| --- | --- |
| `index.html` + `landing/` | صفحة الهبوط (عرض اللعبة، الأسلحة، القوانين، الأسئلة) |
| `play/` | اللعبة: `config.js` مصدر الحقيقة للأرقام، `game.js` المنسّق، `world.js`، `entities.js`، `weapons.js`، `player.js`، `hud.js`، `ui.js` |
| `public/shots/` | لقطات حقيقية من اللعبة (هيدلس كروم) |
| `tools/` | فحوصات QA آلية: تخطيط اللعبة، صفحة الهبوط، وسلوك اللعب (57 حالة) |

## القوانين والاقتصاد

كل الأرقام معرّفة مرة واحدة في `play/src/config.js` — نفس الأرقام تظهر في صفحة الهبوط لأنها تُستورد من اللعبة مباشرة:
5 قطاعات + وضع لانهائي، 4 أنواع زومبي (زعيم بثلاث مراحل)، 7 أسلحة، 4 خصائص × 8 مستويات لكل سلاح، 4 مهارات.
أقوى سلاح (`Hellfire`) يحتاج عملات **و** بلّورات — البلّورات لا تُشترى، تنزل من الموجات والزعماء وخزائن الجوائز.

## الفحوصات

```bash
node tools/qa.mjs           # تخطيط اللعبة على 9 مقاسات شاشة
node tools/qa-landing.mjs   # صفحة الهبوط على 8 مقاسات
node tools/qa-gameplay.mjs  # 57 اختبار سلوكي (اقتصاد، حفظ، قتل، موجات، زعيم، موت)
```
